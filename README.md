## Live Demo

🔗 [https://BlaxBerry333.github.io/venomous-portfolio](https://BlaxBerry333.github.io/venomous-portfolio)

## Features

- Multi-theme architecture (Warhammer 40K: Tzeentch / Slaanesh, Devil May Cry: Dante / Vergil)
- Multi-language support (日本語 / English / 中文)
- Interactive WebGL backgrounds that persist across page navigation
- Page and theme transitions with the View Transitions API
- Responsive layout with safe-area support for notched devices
- SEO meta tags, Open Graph, and hreflang alternates for every page
